While my websites were completely workable and were completely functional for all intents and purposes, there was still some elements missing
from the production side.

What followed was two months of IT work, software management, an entire redesign of my project management system, and a newfound focus on
color theory.

## Accomplishments

- Redesigned dozens of components to act more responsive
- Revised all image tags on each website, striving for the WCAG 2.2 AA standard
- Transfered projects to the pnpm package manager, saving space and increasing efficiency of coding
- Redeployed websites on the Cloudflare Workers platform
- Upgraded Astro and other npm packages through major breaking changes

## Statistics

- 100% of the home page of [lwumusic.com](https://lwumusic.com) is now fully WCAG 2.2 AA compliant, up from 85%
- Five websites migrated to Cloudflare Workers and the pnpm package manager in three hours

## The Main Issues

These websites were fine on their own. They served their purpose - they looked pretty, showed portfolios of what I've been doing and what's next, and, 
most importantly, they were low cost. There was no reason for change to happen.

However, looking at another website I consistently check (that being the ABC News website in Australia) made me realize this implementation of
color theory was woefully lacking.

Additionally, every time I attempted to read an article from my phone, I realized that components would just sometimes not fit on screen. This was an issue.

## Solving These Problems

I put together an action plan to help fix these things.

1. Figure out when you're going to actually go in and fix these things
2. Migrate to CloudFlare Workers because I got an email about it
3. Write new code to display old content
4. Upgrade old content to WCAG standards
5. Build out new websites for different hobbies

I'm putting off number 5 until next year, but everything else is still very much on the table.

I had some free time open up in October for me to start moving everything over. After that, it was just some simple rewriting of some components that I already made for my music website, a few bits of design, and making sure that everything had "alt" tags to allow for screenreaders to easily read the website.
